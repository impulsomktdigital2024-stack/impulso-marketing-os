# Raio-X Digital Android

Aplicativo Android do Raio-X Digital Express. O app carrega a versão publicada do produto em uma WebView segura, mantém os links internos dentro do app e abre pagamentos Asaas e outros links externos no navegador do dispositivo.

## Endereço conectado

https://raio-x-digital-express-38wa3a.v2.appdeploy.ai/

## Build

O workflow `Build Raio-X Digital APK` gera um APK Android instalável e o publica como artifact do GitHub Actions.
